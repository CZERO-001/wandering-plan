# QL2 卖出日 -9% 止损研究摘要（V1.1 依据）

## 结论

- 在「流浪计划」组合账户上，给 QL2 增加卖出日 -9% 止损（B1/V12 不动）：
  - 期末权益：26,617,924 元 → **28,527,807 元（+7.18%）**
  - 2026 年：+65.71% → **+72.50%**
  - 最大回撤：-40.69% → **-39.65%**
  - QL2 提前出场 19 笔（占 270 笔的 7.0%）
- 分年度：2022 +136.99%、2023 +185.97%、2024 +771.86%、2025 +179.88%、2026 +72.50%
- 触发样例：300996 +4.58pp、002181 +4.10pp、002336 +3.80pp、000504 +3.01pp；也有变差案例（300814 -4.18pp）
- 2023 年小幅落后基线（-7.5pp），2022/2024/2025/2026 均改善；整体属于规则级小改动，不依赖高开行情。

## 方法

- 数据：站点 614 笔账本（B1 313 / QL2 270 / V12 31），卖出日 1 分钟 OHLC（2022-2026；2026-08-07 后 24 笔用 pytdx 补齐）
- 规则：卖出日盘中最低价 ≤ 买入价×0.91 时，以 min(开盘, 0.91×买入价) 卖出；同分钟双触发按先止损；跌停不可卖回退收盘
- 参数：仅测试止损 -5% ~ -15%；-9% 为收益最高点，-8% 最大回撤更优
- 账户：2 仓×50%、共享现金、0.21% 成本，与站点账本同口径

## 样本外提示

- 全区间最优参数属于样本内最优；用 2022-2024 选参、2025-2026 验证时，2025 会跑输基线
- 建议先模拟盘验证 1-2 个月，重点核对集合竞价高开与盘中触价成交
