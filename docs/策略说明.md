# 流浪计划 · 策略说明（V1.1）

## 1. 三路信号

### B1 爆破（短线脉冲）
- 六条件同时成立（T 日收盘）：ret_1 ≤ −4.767%；range_60_b ≥ 0.628；range_compression_20_60_b ≥ 0.714；price_vs_ma60_b ≥ 1.21%；w_amp_first10 > 13.22%；w_std_ret > 8.75%
- 执行：T+3 开盘买入，T+4 收盘卖出（持有 1 个交易日）
- 单路上限 2 只

### QL2 冠军（L2 五因子）
- 五条件同时成立：t_count ≥ 22991；O3 ≥ 0.6539；C2 ≥ 0.6182；C4 ≥ 0.6435；N05 ≥ 0.0526
- 在当日候选里按 candidate_score 取第 1 名
- 执行：T+2 开盘买入；卖出日（T+3）盘中最低价 ≤ 买入价 × 0.91 时止损卖出，成交价 = min(当日开盘, 0.91×买入价)；若成交价已到跌停（无法卖出）则回退收盘卖；未触发则 15:00 收盘卖
- 单路上限 1 只

### V12 双波（O1+C3 + V1.2 离场）
- 入场与双波 V1.1 相同：O1 与 C3 同时成立，T+4 开盘买入
- 离场：默认持有 22 个交易日收盘卖；若「前一日收盘涨停 且 当日收盘未涨停 且 浮盈 ≥ 20%」则当日收盘卖出；收盘跌停顺延
- 单路上限 2 只

## 2. 组合规则
- 最多 2 个仓位，每仓 = 总权益的 50%
- 同日多信号优先级：B1 > QL2 > V12
- 开盘价 ≥ 涨停价 − 0.011 → 放弃该笔
- 不加杠杆、不补仓、不摊平

## 3. 回测口径
- 2022-01-06 ~ 2026-10-27，初始 10 万，含成本 0.21%/笔，复权价重算
- 结果：期末约 28,527,959 元（约 285 倍），年化约 224%，最大回撤 −39.65%
- 分年度：2022 +136.99% / 2023 +185.96% / 2024 +771.86% / 2025 +179.88% / 2026 +72.51%
- 614 笔（B1 313 / QL2 270 / V12 31），QL2 止损 19 笔（历史 18 + 实盘 000504 1 笔）
- 风险：右偏明显，收益依赖少数大赢单；历史收益不代表未来，v1.1 止损阈值来自历史研究，需模拟盘验证

## 4. QL2 止损执行细节
- 判定：卖出日最低价（raw 口径）≤ 买入价 × 0.91；
- 成交：min(卖出日开盘价, 0.91 × 买入价)，若开盘已低于阈值按开盘价成交；
- 跌停保护：若成交价 ≤ 跌停价 + 0.011，视为无法卖出，回退收盘价；
- 历史回测用 PIT 复权日线判定；实盘/日更用 raw_sina + daily_extra 原始行情判定，两者各自在本口径内自洽；
- B1/V12 不受影响；不改变选股、买入日、持有天数、仓位与优先级。
