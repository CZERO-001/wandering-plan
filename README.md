# 流浪计划（Wandering Plan）· V1.1

> B1 爆破 + 冠军 L2（QL2）+ 双波 O1+C3（V1.2 离场）三路组合。
> **研究演示，不构成投资建议。** 每日信号与交易数据只保存在本机，仓库只放代码。

## 策略一句话

三条独立信号线并行，最多 2 个仓位、每仓 50%，优先级 **B1 > QL2 > V12**：

| 信号 | 规则来源 | 买入 | 卖出 |
|---|---|---|---|
| B1 爆破 | O2 + N05 + N06 六条件 | T+3 开盘 | T+4 收盘（持 1 天） |
| QL2 冠军 | L2 五因子（t_count/O3/C2/C4/N05），取候选第 1 | T+2 开盘 | **T+3 盘中 -9% 止损，否则收盘** |
| V12 双波 | O1+C3，V1.2 离场 | T+4 开盘 | 22 个交易日收盘；或涨停打开且浮盈 ≥20% 当日收盘；跌停顺延 |

通用：开盘价 ≥ 涨停价−0.011 不买；最多 2 仓；不加杠杆、不补仓。

### V1.1 新增：QL2 卖出日 -9% 止损

- 卖出日（买入后次日）09:30–14:57，若盘中最低价 ≤ 买入价 × 0.91，则止损卖出；
- 成交价 = min(当日开盘价, 0.91 × 买入价)；若成交价已到跌停（无法卖出），回退收盘卖；
- 未触发则仍按 15:00 收盘价卖出。B1、V12 规则不变。

## 每日流程

python -m src.daily_run：数据新鲜度检查 → 三路信号 → 组合排程 → 生成公网页面 → scp 到 ZPC → 微信通知（失败告警）。

## 公网页面

- 页面地址：https://<ZPC 隧道域名>/wandering-plan/ （隧道重启后域名会变，见 WeChat 通知或 ZPC 的 current_url.txt）
- 页面顶部「今日作战」：今日持仓、今日操作、明日买卖提醒（QL2 明日卖出会显示止损价）
- 页面含资金曲线（逐笔复利，10 万起）、年度曲线、年度/个股/逐笔明细
- 无需登录，不展示账本/个人信息

## 每日自动化

- 本机计划任务：
  - AStock_WanderingPlan_Morning：工作日 08:30，早更（数据补到上一完成交易日 + 重建页面）
  - AStock_WanderingPlan_Noon：工作日 12:00，盘中持仓快照（现价/浮动盈亏/QL2 止损价）
  - AStock_WanderingPlan_Daily：工作日 17:45，收盘日更（信号/持仓/明日提醒/个股/年度）
- 流程：数据新鲜度检查 → 缺数据自动补（PIT/Tencent 日线、QL2、B1、V12）→ 信号 → 页面 → scp 到 ZPC → 微信通知
- 任务已设置 StartWhenAvailable，唤醒后可补跑；数据补不齐时页面显示「信号未更新」并告警
- 2026-10-29 修复：PIT 刷新结束日不再读旧的 data/raw/000001.csv，改为显式 -EndDate / raw_sina 最新日期；新增腾讯 kline 批量补日线（fetch_missing_daily_fast.py）；QL2 的日线因子在通达信客户端不可用时改用 PIT 数据补齐（scripts/build_qld_daily_from_pit.py）；新增 08:30 早更、12:00 盘中持仓快照。
