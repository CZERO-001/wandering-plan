# 流浪计划（Wandering Plan）

> B1 爆破 + 冠军 L2（QL2）+ 双波 O1+C3（V1.2 离场）三路组合。
> **研究演示，不构成投资建议。** 每日信号与交易数据只保存在本机，仓库只放代码。

## 策略一句话

三条独立信号线并行，最多 2 个仓位、每仓 50%，优先级 **B1 > QL2 > V12**：

| 信号 | 规则来源 | 买入 | 卖出 |
|---|---|---|---|
| B1 爆破 | O2 + N05 + N06 六条件 | T+3 开盘 | T+4 收盘（持 1 天） |
| QL2 冠军 | L2 五因子（t_count/O3/C2/C4/N05），取候选第 1 | T+2 开盘 | T+3 收盘（持 1 天） |
| V12 双波 | O1+C3，V1.2 离场 | T+4 开盘 | 22 个交易日收盘；或涨停打开且浮盈 ≥20% 当日收盘；跌停顺延 |

通用：开盘价 ≥ 涨停价−0.011 不买；最多 2 仓；不加杠杆、不补仓。

## 回测摘要（2022–2026，含成本，可执行版）

- 组合：10 万 → 约 299 倍，年化 ~234%，最大回撤 −40.7%
- 分策略单笔：B1 +2.0% / QL2 +1.0% / V12 +14.0%
- 风险：收益依赖少数大赢单，剔除最大 20 笔后约 57 倍；**历史收益不代表未来**

## 目录

- `src/` 信号计算、组合排程、公网页面生成、数据新鲜度检查
- `tests/` 单元测试（V1.2 离场两个真实案例、组合优先级、页面渲染）
- `docs/策略说明.md` 规则与口径细节

## 每日流程

`python -m src.daily_run`：数据新鲜度检查 → 三路信号 → 组合排程 → 生成公网页面 → 推送。

## 公网页面

- 页面地址：`https://<ZPC 隧道域名>/wandering-plan/`（隧道重启后域名会变，见 WeChat 通知或 ZPC 的 `current_url.txt`）
- 页面三状态：今天要买（大字显示股票/买入时间/卖出时间/仓位）、今天不用买、信号未更新
- 无需登录，不展示持仓/账本/个人信息

## 每日自动化

- 本机计划任务 `AStock_WanderingPlan_Daily`：工作日 17:45 运行 `czero_web/scripts/run_wandering_plan_daily.ps1`
- 流程：数据新鲜度检查 → 缺数据自动补（PIT 数据集 / L2 因子 / V1.1 日更）→ 三路信号 → 组合排程 → 生成页面 → scp 到 ZPC → 微信通知（失败告警）
- 数据补不齐时：页面显示「信号未更新」，任务退出码 1，不发错误信号
